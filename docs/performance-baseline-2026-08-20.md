# PageLumen import performance baseline

These are deterministic XCTest wall-time guards for the embedded-text path, not a
claim about scanned-image OCR performance or peak resident memory.

| Fixture | Guard | Observed on this run |
| --- | ---: | ---: |
| 10-page embedded-text PDF | < 30 s | 0.54 s |
| 50-page mixed-content text fixture | < 90 s | 0.32 s |

The fixtures are generated by `DocumentProcessorTests` and run in the package
test target. The 100-page budget rejection and malformed PDF/image tests cover
oversized/damaged inputs. Peak resident memory, scanned-image OCR latency, and
device-to-device comparisons remain physical-device release gates and must not
be inferred from these wall-time guards.
